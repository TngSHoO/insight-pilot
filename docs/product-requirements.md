# InsightPilot 产品需求文档

## 1. 产品背景

产品经理通常需要从应用商店评论、客服工单、问卷和访谈中整理需求。人工处理耗时，普通大模型总结又容易缺少原文依据，导致洞察难以核验。

## 2. 目标用户

- 需要定期整理用户反馈的产品经理
- 负责VOC分析的用户研究或客户成功人员
- 需要快速形成需求池的创业团队

## 3. 核心问题

1. 反馈来源分散，整理成本高。
2. 相似问题难以聚类和统计。
3. AI结论缺少证据，存在幻觉风险。
4. 洞察与需求文档之间仍需大量人工转换。

## 4. MVP范围

### 本期包含

- CSV上传、文本粘贴和示例数据
- 反馈文本列选择
- 痛点聚类、频次和严重程度
- 需求建议与P0/P1/P2优先级
- 原文编号引用
- PRD初稿
- Markdown和JSON下载

### 本期不包含

- 多人协作和账号权限
- 云端永久存储
- 自动连接客服或应用商店平台
- 无人工审核的自动发布需求

## 5. 成功指标

- 结构化JSON正确率不低于95%
- 引用准确率不低于90%
- 20条反馈在可接受时间内完成分析
- 产品经理人工可用性评分不低于4/5

## 6. 风险控制

- 强制要求结论引用原文编号
- 在界面中展示本地运行与人工复核提示
- 不默认保存用户原始数据
- 通过低温度参数降低输出随机性
